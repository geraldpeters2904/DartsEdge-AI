# DartsEdge AI v1.4.0 — Strategy Engine

**Build:** 001  
**Release date:** 26 July 2026

## Highlights

- Versioned strategy profiles with exactly one active strategy.
- Validated EV, edge, confidence, Kelly, exposure, odds, market and competition rules.
- Strategy editor with immutable history, duplication and JSON import/export.
- Guarded Decision Engine with shadow and active enforcement modes.
- Strategy Analytics with acceptance, rejection, settlement, ROI, win rate and drawdown.
- Warning-free template compatibility layer and corrected test file handling.
- GitHub Actions regression testing on Python 3.9 and 3.12.

## Safety

- The Player Intelligence model remains `Intelligence-0.1-shadow`.
- Strategy enforcement is not activated automatically during installation.
- Unsettled decisions are excluded from ROI, win-rate and drawdown calculations.
- Paper strategies cannot surface live accepted bets.
