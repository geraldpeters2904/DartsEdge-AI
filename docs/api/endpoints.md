# API Endpoints

## Diagnostics

- `GET /version` — application and model version metadata.
- `GET /health` — health status and component checks.
- `GET /api/data-providers` — fixture provider diagnostics.
- `GET /api/odds-providers` — odds provider diagnostics.
- `GET /api/automation` — scheduler and job status.
- `GET /api/strategies` — strategy registry and active profile.
- `GET /api/strategy-analytics` — current strategy analytics report.

The HTML pages remain the primary interface; these endpoints support diagnostics and future integrations.
