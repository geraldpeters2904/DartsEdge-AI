# DartsEdge AI v1.1.1 — Mission Control

Version 1.1.1 turns the application into an operational analytics workspace.

## Highlights
- Mission Control summarises opportunities, portfolio risk, model health and alerts.
- Opportunity Ranking prioritises model signals without calling them value bets until odds are available.
- Portfolio Health tracks bankroll, exposure, returns, concentration and risk status.
- AI Coach converts analytics into prioritised, risk-aware actions.
- Dashboard Polish provides a consistent responsive interface.
- Diagnostics exposes release and runtime health information.

## Upgrade notes
- No database migration is required.
- Install development dependencies with `pip install -r requirements-dev.txt`.
- Validate the release with `python -m unittest discover -s tests -p 'test_*.py'`.
