# DartsEdge AI v1.2.0 — Intelligence Engine

Released: 26 July 2026  
Build: 001  
Model: Intelligence-0.1-shadow

## Overview

Version 1.2.0 adds the evidence and explainability layer required to improve DartsEdge AI scientifically. The existing legacy prediction engine remains official while the new Player Intelligence model runs alongside it in shadow mode.

## Highlights

- Configure and version Player Intelligence weight profiles.
- Inspect factor-level reasons behind predictions.
- Distinguish prediction confidence from explanation confidence.
- Preserve immutable prediction snapshots with UUIDs.
- Settle audited predictions through append-only outcome events.
- Compare legacy and intelligence models using accuracy, Brier score and calibration.
- Analyse profile, tournament, confidence-band and performance-drift results.

## Important operating note

The Intelligence model is not promoted automatically. Results remain provisional until enough audited predictions have been settled. The application warns when the sample is below 25 comparisons, and unsettled predictions never count as evidence.

## Upgrade

No Alembic migration command is required. The application creates the new audit tables through its existing SQLAlchemy startup process. Back up the database before installation and restart FastAPI after applying the release.

## Rollback

Use the included `rollback.sh` script. It restores the files backed up by the release installer. Audit tables and records are deliberately left intact so historical evidence is not destroyed.
